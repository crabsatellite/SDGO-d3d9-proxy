使用方法

<link rel="stylesheet" href="/ui.css">            组件与令牌
<script type="module" src="/ui.js"></script>    图标、标志、客户端美术、构建函数

import {icon, mark, hero, chip, led, status, stat, gauge, applyArt} from '/ui.js';
root.append(hero({eyebrow: 'MOD HANGAR', title: host.name, stats: [{value: 7, label: '功能'}]}));
button.prepend(icon('settings'));
applyArt(element, 'hangar');          // 成功读取后设置 --art，并加上 has-art

旧面板：放在 .ui-auto 里，普通 button / input / select / textarea / 复选框 / table / details
自动套用组件样式；元素自己写的 .ui-* 类优先，.ui-plain 可以排除。
影子 DOM 面板：--ui-* 变量会继承进去，可以在 :host 里写 var(--ui-gold, 原颜色)。
