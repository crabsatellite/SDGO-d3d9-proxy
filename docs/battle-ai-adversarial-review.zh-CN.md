# Battle AI 0.3.2 敌对审查

本轮分别从 Medium、Hard、导航防御和原生资源桥四个方向独立审查，再用相反场景复核修复。
审查目标同时包括战斗能力和主线程计算开销。实际游戏没有启动，FRP、现有服务与数据库没有更新。

## 难度规则

| 项目 | Medium：普通玩家高手 | Hard：极致玩家高手 |
|---|---|---|
| 决策／输出 | 每次原生更新决策，无人为 idle；保持原生冷却和动作限制 | 相同基础 |
| 瞄准 | 保留精准方向和有证据的弹速预判，不用随机打空降难度 | 相同；真实命中率需实测 |
| 移动 | 基础地面走射、贴近时后退、冷却时走位、正面防御 | 另有空中横摆、探头、绕后、走 A |
| 必杀 | 被抓或受到明确压力时解围 | 另在目标受控／近战动作的明确机会主动使用 |
| 必杀取舍 | 不对可普通收头的远程压力浪费 SP；真实反控例外 | 不抢队友抓取、不抢防御逃生；入场前继续复核机会 |
| 专家技巧 | 不额外加装部件／道具，不甩刀或编织 | 甩刀、刀枪编织、盾面利用、合法部件及限次道具 |
| 防御搬位 | 同一压力事件目的地限制在起点半径 480 内 | 半径 1200；两档都防止无限搬离战区 |

该必杀分档已由用户确认。两档均不增加凭空伤害、不补弹、不绕过真实武器和控制权限。

## 已直接修正的退化

| 缺陷／触发 | 后果 | 修正 |
|---|---|---|
| 直接侧移仍持有旧追击 path | Think 尾部旧 waypoint 覆盖侧移／后退 | 直接移动显式移交路线所有权；保留防御逃生优先级 |
| 无弹分支早于防御移动判断 | 装填时放弃护背路线 | 关火但保留逃生路线 |
| 已到达路径到下一帧才回收 | 陈旧 routeActive 占用决策 | 观察前推进路径生命周期 |
| 探头丢视线、回撤失败／路线中途丢失 | 停走抖动或等不存在的路线 | 不可见不探头；丢路径立即重建，失败退出战术 |
| 绕后布尔值存活但原生 path 已消失 | 假装仍在移动，压住其他战术 | 根据真实路线、到达和原生移动窗口判定 |
| 编织要求第二枪，但已无远程弹药 | 最多等待 6.5 秒的不可完成阶段 | 远程失效立即进入回刀阶段；不伪造射击回执 |
| 满 SP 对任意目标自动必杀 | 打断辅助火力、过杀、抢队友连段 | 按已确认的 Medium／Hard 规则选机会并在入场前重验 |
| 原武器槽变形后失效、归位永久拒绝 | 必杀租约无限占用控制 | 失效槽立即交还，拒绝归位有界交接；Easy／关闭路径同样处理 |
| 旧必杀确认残留、完成回执缺失 | 后续施放把旧确认当本次，或长期等待 | 新施放绑定确认序列基线；真实 busy 优先；缺回执有界退出 |
| 一台机体连续三次脚本错误 | 全场增强 AI 永久回退原版 | 按单位及 generation 隔离，成功清连续错误，重载可重试 |
| 防御朝向与刚排入的近战动作竞争 | 挥砍朝向可能被转开 | Facing 前轻量重查当前及待执行原生状态，合法近战由原生掌握朝向 |
| 远处闲置敌人与近处威胁等权 | 无谓侧转、连续搬位 | 闲置远敌不强迫防御；真实进攻／近期命中保留 |
| 最佳防御点不可达、攻击者已死 | 固定重试同一点或点路径无故失败 | 最多三个导航尝试；明确目的地不要求目标对象存活 |
| 理论高 DPS／相同分数反复切枪 | 支付切换成本而错过现成收头 | 已就绪且可预计收头或等分时保留当前武器 |

## 计算开销

- 朝向候选循环预先归一化威胁；避免每个候选重复平方根与方向计算。
- `ApplyDefence` 不再重读整套能力；仅轻量重查动作状态，非盾防不读取盾牌。
- 每次能力快照内缓存可读内存区域；跨调用不缓存，每次复制仍保留 SEH 和范围检查。
- Hard 掩体广搜拆到多个原生 Think：每帧一个隐藏点候选，最多 46 条几何射线（含最终重验）。同帧重复调用不会重复广搜；搜索期间普通战斗继续。
- 目标记忆复用 Lua 表，删除已移除字段，减少反复分配。

Win32 Release 局部基准：120 组场景的朝向／位移结果与修改前一致。450 次完整防御位移求解：

| 威胁数 | 原耗时 | 修改后耗时 | 局部加速 |
|---|---:|---:|---:|
| 1 | 58.4 ms | 35.8 ms | 1.63× |
| 4 | 144.4 ms | 48.2 ms | 2.99× |
| 12 | 424.4 ms | 79.9 ms | 5.31× |
| 32 | 1268.4 ms | 192.5 ms | 6.59× |

这不是实际游戏 FPS 或多人性能结论。

## 验证与保留的不确定性

本轮离线结果：152 个通用策略场景、26 个能力／保护页检查、7 类原生客户端桥场景、30 组原版字节码回放、12 项相关 CTest、安装配置保留检查通过。
原生测试新增了采样后排入近战、远处闲置敌人、分帧掩体预算、护背目的地半径及锚点过期、死目标点寻路和备选路线反例。

原生 `ChangeWeapon` 静态核对发现已有接受后的幂等门；未证明重复请求会重启动作，因此保留下一帧合法重试，不增加人为切枪等待。

尚需手测／实机采样的项目：

- 实际复杂地图、动画、网络时序、操作手感、胜率与约 90% 的命中目标。
- 多 Hard 同时搜索掩体的主线程峰值，以及持续逐目标视线碰撞查询；本轮没有用过期视线换取性能。
- `damage / 配置冷却` 不是完整武器 DPS；未知脚本武器、蓄力及完整动画周期尚未做在线学习评分。
- 跨重生排队的 SP 通知没有原生 generation/cast ID，理论上仍有旧消息晚到风险；尚无实际故障证据，本轮未改网络协议或重生资源规则。

源码位于独立分支。部署仅更新独立 AI 客户端／BattleServer 副本，未配置或启动隔离 SQL/SIP 后端。
